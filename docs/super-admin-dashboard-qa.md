# צ׳ק ליסט בדיקה — סופר אדמין (Dashboard מלא)

מסמך לבדיקה **ידנית** לאחר התחברות כ־**`super_admin`**.  
מטרה: לוודא שכל אזורי ה־Admin נטענים, הפעולות נשמרות למסד, וההתנהגות עקבית.

**ערוץ Admin (ייצור):** `https://hotel-management-rho-two.vercel.app`  
**כניסה:** `/login`

---

## לפני שמתחילים

| פריט | פעולה |
|------|--------|
| משתמש | חשבון עם `role = super_admin` בטבלת `users` + אותו משתמש ב־Supabase Auth |
| עוגיה | התחברות דרך הדפדפן — נשמרת עוגיית `sb-access-token` (אימות הפאנל) |
| `manage-user` | אם אתם יוצרים/מעדכנים משתמשים מהפאנל — לפרוס את ה־Edge Function המעודכן בסופבייס |
| בנייה קודית | מתוך `admin/`: `npx tsc --noEmit` · `npm run lint` · (אופציונלי) `npm run build` |

בדיקה אוטומטית אחרונה במאגר: **TypeScript + ESLint עברו בהצלחה** על קוד ה־Admin.

---

## מה הסנכרון אומר בתרחיש הזה?

- הנתונים ב־**Dashboard** נטענים בעיקר מה־**שרת Next.js** שמשתמש ב־**Service Role ל־Supabase** (`supabaseAdmin`) — לא מסתמכים על RLS של הלקוח.
- רוב העמודים **לא פותחים WebSocket מתמשך** מהדפדפן: לאחר פעולה באפליקציית צווט / PWA כדאי **לרענן את העמוד** ב־Admin כדי לראות עדכון מיידי.
- **אוטומציות**, **משתמשים (דרך API)** וכו׳ מתבססים על **עוגיות** — אין לפתוח את הטאב ב־`/api/...` בטרמינל גולמי בלי העתקת cookies (הבקשות נטענות מתוך הדפדפן המחובר).

## סדר מומלץ לבדיקה (כל המסך)

סמנו ✓ בהתאם למה שראיתם בעיניים.

### 1. כניסה ותפריט
- [ ] `/login` — התחברות מצליחה, מועבר ל־`/dashboard`
- [ ] בסרגל: **כל** הפריטים מופיעים (סקירה, מלונות, משתמשים, אנליטיקה, לוגים, צ׳קליסטים, אוטומציות, בקשות אורחים, משוב)
- [ ] מתג שפה (אם בשימוש) עובד

### 2. סקירה — `/dashboard`
- [ ] מספרים מתעדכנים בהתאם לנתונים (מלונות, משתמשים, קריאות פתוחות ברמת מערכת)
- [ ] הקלקה מהסרגל בין פריטים בלי תקלה

### 3. מלונות — `/dashboard/hotels`
- [ ] טבלה נטענת (שמות, תוכניות, סטטוס, ערכות עיצוב)
- [ ] **ThemePicker** (patch ל־`/api/hotels/[id]`) משנה ערכת צבעים ומרענן / מציג שינוי
- [ ] **New Hotel** — `/dashboard/hotels/new` נפתח (רק סופר) והאשף נשמר עד הסוף (או צעד בסיסי)
- [ ] **עריכת מלון** — `/dashboard/hotels/<id>`
  - שמירה
  - קישורים: חדרים, QR, פוסטר נפתחים
  - **מחיקת מלון** (אימות שם) — רק בסביבות בטוחות

### 4. חדרים — `.../hotels/[id]/rooms`
- [ ] רשימת חדרים, הוספה יחידה, עדכון, מחיקה (זהירות)
- [ ] בולק אד חדרים (אם בשימוש) מחזיר תוצאה

### 5. QR / פוסטר
- [ ] דף QR — קוד גנרטיבי והורדות
- [ ] פוסטר — נפתח בלשונית, ללא קריסה

### 6. משתמשים — `/dashboard/users`
- [ ] רשימה + סינונים (מלון, תפקיד, טקסט)
- [ ] הפעלה/השעיה (כל עוד בסביבת בדיקה)
- [ ] **הוסף משתמש** — `/dashboard/users/new`
- [ ] **עריכה** — `/dashboard/users/[id]` (כולל API `GET .../users/[id]` ללא 403 למשתמשי מלונות אחרים)

### 7. אנליטיקה — `/dashboard/analytics`
- [ ] טבלת תקלות לפי מלון ברמת גלובל (יותר מאשר מלון אחד אם קיים בנתונים)

### 8. Audit logs — `/dashboard/logs`
- [ ] הגישה **נחסמת** למנהלי מלון בלבד (בדוק במקביל עם משתמש שאינו סופר) — כאן: נטען לסופר
- [ ] עד 200 עדכונים, עמודות זמן / מלון / משתמש

### 9. צ׳קליסטים — `/dashboard/checklists` + `/dashboard/checklists/[id]`
- [ ] טעינה מ־`/api/checklists`
- [ ] יצירה / עריכה / פריטים (לפי UI) נשמרים למסד
- [ ] הפעלה כמנהל מלון **אסורה** (רק סופר) — בהקמה נפרדת

### 10. אוטומציות — `/dashboard/automations` + חדש
- [ ] `GET /api/automations` בלי `hotel_id` מחזיר את כולם (גלובלי לסופר)
- [ ] החלפת פעיל, עריכה, מחיקה
- [ ] `/dashboard/automations/new` — יצירה עם `hotel_id`

### 11. בקשות אורחים — `/dashboard/guest-requests`
- [ ] טבלה, סינונים (מלון מלא לסופר)
- [ ] שינוי סטטוס דרך הטופס בטבלה — נשמר (ריענון ומוצג)

### 12. משוב אורחים — `/dashboard/guest-feedback`
- [ ] רשימה, סינון מלון
- [ ] שמירת הערות צוות / מחיקה (סביבת בדיקה)

### 13. התנתקות
- [ ] `POST /api/logout` או זרימת logout מהממשק — חוזרים ל־`/login`

## בדיקת “מה לא אמור לקרות” (רגרסיה הרשאות)

במקביל למשתמש **מנהל מלון** (לא סופר):

- [ ] **אין** גישה ל־`/dashboard/logs`
- [ ] **אין** גישה ל־`/dashboard/checklists`
- [ ] `/dashboard/hotels` מפנה ל־`/dashboard/hotels/<מזהה_המלון>`
- [ ] לא נפתח טופס הקמת מלון חדש בלחיצה אם נחסם בשרת

## רישום בעיות

| תסמין | מה לבדוק |
|---------|-----------|
| 401 בעת שמירה | עוגיה `sb-access-token` / תוקף הסשן |
| 403 ב־`/api/users` | Edge `manage-user` לא מעודכן או הרשאות caller |
| ללא נתונים בטבלאות | פרויקט Supabase לא נכון ב־`.env.local` של Vercel |
| שינוי Theme לא נשמר | Network ל־`PATCH .../api/hotels/[id]` ותשובת 200 |
